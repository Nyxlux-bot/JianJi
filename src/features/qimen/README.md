# 奇门排盘

起盘设置选择转盘、飞盘或星飞门转，支持时间起局与报数起局。转盘时家支持拆补、置闰、茅山三种定局法，八神可切换勾陈/朱雀或白虎/玄武。结果页可在同一记录上切换年、月、日、时盘，并支持时辰前后步进预览与另存新盘。所有盘按输入的北京时间推算，地点仅作记录。转盘、鸣法以子初换日；透派坐山以节入日换年月、零点换日柱，晚子时的时柱按次日五鼠遁。支持 1900–2100 年。

转盘的四个时间类别共用九宫、九星、八门、八神和天地盘干，点标签时保持当前宫位。年盘以 1864 年上元甲子为锚点逐年逆行，月盘按年支分元逐月逆行，日盘以冬夏至最近的甲子日起局逐日顺逆，时盘按交节拆补。八神使用勾陈、朱雀。北京时间 2026-02-22 12:15 的日盘为阳遁一局中元，值符天蓬在兑七，值使休门在巽四。[衍象坊日盘对照](https://profound.fate-craft.com/tools/qmdj?method=rijia&bashen=gouchen&t=2026-02-22T12%3A15)

飞盘采用《奇门鸣法》〈入门〉注文。年局以同治辛未所在小雪下元甲子段为锚，每六十年进一元；月局以同治辛未年庚子月的谷雨中元为锚，每六十月进一元。日局按年支及自冬至起的六段换元，时局按交节拆补。星门皆顺飞，五位随门序飞移，九神阳顺阴逆。年月日是按注文推演。[〈入门〉及注文](https://qimen.yi958.com/qmfp/5675)

星飞门转采用透派坐山。年盘自 1864 年立春起阳一，每二十年进一局；月盘按三元五年段局表；日盘取近二至甲子，二十日一局，闰段前后三十日分接两遁；时盘取冬至符头依五日局表，闰大雪复用最后三局。九星顺飞、八门外转。年、月盘和日、时盘分别处理值使入中、旬首入中和本柱天干入中。[坐山四盘作法](https://ktonko.com/html/ban/65_matome.html) · [定局与闰段](https://ktonko.com/html/kyoku_z/complement.html)

`engine.ts` 使用项目已有 `tyme4ts` 的 `SolarTime.getTerm()` 与 `getSixtyCycleHour()`，按交节瞬间确定节气、年柱和月柱，不使用旧六爻的近似节气日期。直接读取干支时，避免其他排盘模块更换全局八字 provider 后影响日界。输入以北京时间字符串保存，计算不依赖设备时区。

转盘的地盘按数字九宫阳顺阴逆布三奇六仪；星、门保持后天外环顺序整体旋转；值使先从旬首原宫飞九宫，再处理中五寄宫。八神阳顺阴逆；空亡、驿马取所选类别对应的柱。中五保留地盘干，天禽随芮的天盘寄干与坤二的地盘寄干分别保存。

参考公式与对照盘例：[qimen-rs 算法说明](https://github.com/SpenserCai/qimen-rs/blob/main/docs/algorithm-sources.md)、[2026-09-18 15:00 盘例](https://github.com/SpenserCai/qimen-rs/blob/main/docs/examples/2026-09-18T150000%2B0800.json)。实现独立编写，不增加运行时排盘依赖。

详情的九星月令旺衰采用《烟波钓叟歌》口径，八门采用一般五行法（年盘跨全年不套单月令）；门克宫为门迫，宫克门为受制。三种盘式均统一标注旬空、驿马、门宫生克、六仪击刑、古典三奇墓（乙未、丙戌、丁丑）、星门伏吟/反吟、十干克应（81 组合格局）与五不遇时，转盘另支持暗干（隐干）显示。[注记公式与原典链接](https://github.com/SpenserCai/qimen-rs/blob/main/docs/extensions.md)。程序注记不直接等同于问事结论。

记录保存原始时间、盘式、规则版本、时家转盘基础快照与 AI 会话。较早记录缺少盘式时按转盘读取。其余视图从保存的四柱及基础快照派生，再次起盘生成新记录。AI 合读同一时刻四盘，单盘导出保留当前标签。AI 引用使用盘面里的中文标记，如【月盘·兑七宫】。程序据此生成对应盘与宫的链接。历史回复中已写明盘别和宫名的引用也按文字定位，早期只带宫号的地址默认回到时盘。

九宫采用连续外框，单击选宫、双击打开居中的宫位放大卡；左右滑动或底部按钮按盘面行序切宫，盘面注记可展开阅读。双击卡内盘面、点空白或关闭按钮返回九宫；屏幕阅读器激活可直接打开详情。放大卡使用缩放淡入，减少动态效果时直接呈现。

右上角 AI 入口复用 `ResultTopBar`、`AIChatModal`、分析任务与追问流程，不单独创建奇门 AI 页签。AI 规则与盘面资料分开传递，完整九宫、八宫间的五行生克、占问和用户背景进入用户消息；从详情发起时携带对应宫名，AI 回答中的宫位链接返回盘面并选中该宫。选中宫位只代表关注位置，取用由 AI 根据实际问题解释，不预设本人或事项。

初次解读先答占问，再分时、日、月、年解释各自的依据与具体应对姿态，通常 450–700 字；追问通常 100–220 字，支持基于四盘分歧的快捷追问。资料附带近期 14 日干支与后续两节气对照，用于准确落定出空与交节窗口。导出分享与复制均自动还原为纯中文宫位标记【盘·宫】。流式传输正常结束后，短追问或缺少隐藏完成标记不会被误判为中断；网络中断和输出上限仍由传输层报告。

首页与八门图片来自本次已确认的 ImageGen 素材。八门图形按《遁甲演义》的八门本宫对应与《说卦》取象作现代设计，图片本身不参与算法。


四盘对照支持固定一宫比较星、门、神及天地干，也可追踪同一八门在四盘的落点。点对照行即可转到相应盘宫。「沿用此盘再起」从来源记录预填表单，另存关联新盘。结果页的「复盘」按观察日期保存期限、所选卷当时的判断及实际观察，和 AI 对话分别存储。

新解读保留生成时使用的四盘资料和盘式版本，追问与导出沿用这份快照。完整四卷逐卷绑定盘据；客户端从快照补上事实与回宫入口，识别到错误的星门属性或生克方向时显示具体原因并允许重试。旧解读保留原文。单盘导出取总断与所选卷，整段问答从 AI 页的会话导出入口取得。
